# GREEN-API Test Task

Тестовое задание на должность «Специалист технической поддержки 2 линии».

## Реализовано

- `getSettings`
- `getStateInstance`
- `sendMessage`
- `sendFileByUrl`

Технологии:

- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API
- REST API GREEN-API

## Запуск

Проект не требует установки зависимостей.

Можно открыть `index.html` локально или разместить репозиторий через GitHub Pages.

Для работы необходимо создать инстанс GREEN-API, авторизовать WhatsApp-номер и использовать `idInstance` и `ApiTokenInstance` из личного кабинета.

## Безопасность

Токен вводится пользователем непосредственно в браузере и не хранится в репозитории. Не размещайте реальные токены в исходном коде, README или GitHub.
